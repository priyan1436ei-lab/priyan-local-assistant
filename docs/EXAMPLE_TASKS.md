# Example prompts

## Chat and learning

“Explain recursion in Thenglish. Give one Python example and a small practice question.”

“Help me plan my next two hours. Ask what deadline matters most before making the plan.”

## Save useful information

“Remember that I prefer concise explanations with examples.”

“Create a task called Finish my database assignment.”

“Save a note titled Project checklist: test login, validate inputs, review error messages.”

“Remind me on 12 October 2026 at 19:00 Asia/Kolkata to review my portfolio.”

## Documents

Import the file, then enable Use my documents:

“From my notes, explain the section mentioning database normalization. Cite the retrieved passage.”

Use specific source words. Keyword retrieval cannot reliably map an English question to unrelated Tamil terms or vice versa.

## Coding agent

“Build a Python command-line expense tracker using only the standard library. Store expenses in CSV. Include add, list and total commands. Create unit tests, run them and repair failures. Add a README with examples.”

“Inspect the Python files in the workspace. Identify one actual bug, explain it briefly, fix it, and run a relevant test. Preserve unrelated behavior.”

“Create a static HTML/CSS personal portfolio with no external dependencies. Save index.html and styles.css. Check links and file references.”

Keep tasks bounded. The agent does not have a browser verification tool or internet search. It should state those limits rather than invent a screenshot, deployment or search result.
