MADE TO FEEL LIKE YOURS

Your setup.

Personal & model settings

PC commands run with your permissions. Sandbox commands run without network, with only the workspace mounted. Docker and the prepared image must already be installed.

Get ready in three steps

  1. Install Python 3.11 or 3.12 (64-bit).
  2. Run install-windows.bat once. It installs the embedded engine and downloads the local model.
  3. Double-click start-windows.bat. No separate model server is needed.

Model weights are separate downloads. No Ollama, model server or cloud API keys needed. Detailed Windows instructions are in SETUP.md.

Offline voice

python -m pip install -r requirements-voice.txt
python setup.py --voice

Voice recognition runs locally on CPU. Speech output uses installed OS voices; Tamil output needs an appropriate OS voice. No browser cloud speech recognition is used.
